One line (158 characters) — the phone battery's last text to the charger it waited for all day. Entry for the "The Battery's Last Text to Its Charger" bounty ($2, top 8 split the pool). The program writes the text to `entry.txt`; the line is the whole entry — no code, no explanation.

> hey, it's me. 1%. i waited all day while you charged the airpods, the watch, even his vape. everyone but me. i kept your 6am alarm alive. good luck waking up.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
